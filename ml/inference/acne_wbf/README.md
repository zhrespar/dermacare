
# DermaCare AI — Acne WBF Ensemble

YOLO11s V1 + YOLO11s V4 ensemble for acne lesion detection.

- Fusion: Weighted Boxes Fusion (WBF)
- Model weights: [1, 2]
- WBF IoU threshold: 0.55
- Preview confidence threshold: 0.10
- Validation mAP@50: 0.413716

Model checkpoints are stored separately and are not included in GitHub.

This is a research prototype for cosmetic decision support.
It is not intended for medical diagnosis.
